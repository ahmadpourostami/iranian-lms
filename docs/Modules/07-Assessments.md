# Assessments Module

**Version:** 1.0
**Status:** Draft

---

# 1. Purpose

The Assessments module is responsible for evaluating learner knowledge and performance throughout the learning process.

It provides a flexible assessment system capable of managing quizzes, assignments, exams, grading, submissions, attempts, feedback, and assessment analytics.

The module measures learning outcomes but does not manage course content or learning progress.

---

# 2. Responsibilities

The Assessments module is responsible for:

* Quizzes
* Assignments
* Exams
* Question Banks
* Attempts
* Grading
* Submissions
* Instructor Feedback
* Assessment Rules
* Assessment Analytics
* Plagiarism Integration (Future)

---

# 3. Business Boundaries

The Assessments module owns:

* Assessments
* Questions
* Attempts
* Answers
* Grades
* Feedback
* Submission History

The module does **not** own:

* Courses
* Lessons
* Learning Progress
* Certificates
* Enrollments

# 31. Design Decision

The Assessments module intentionally separates **Assessment Definition** from **Assessment Attempts**.

```text id="y1ex7m"
Assessment
│
├── Questions
├── Rules
└── Settings

↓

Attempts
│
├── Answers
├── Score
├── Feedback
└── Status
```

This separation ensures that changes to an assessment do not affect historical attempts, preserving auditability, reporting accuracy, and long-term data integrity.

It also enables future features such as assessment versioning, AI-assisted grading, adaptive testing, and detailed learning analytics without redesigning the module.
