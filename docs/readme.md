# Iran LMS Documentation

This directory contains the technical documentation for Iran LMS.

Iran LMS is a professional Learning Management System developed as a
WordPress Plugin.

## Documentation Structure

- `00-Overview` — Project overview and product definition
- `01-Architecture` — System architecture
- `02-Database` — Database design
- `03-API` — API specifications
- `04-Modules` — Plugin modules
- `05-UI` — UI/UX and design system
- `06-Components` — UI components
- `07-Mobile` — Mobile application and responsive specifications
- `08-Developer` — Development standards

The documentation is the primary reference for implementing the plugin.
